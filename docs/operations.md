# Эксплуатация

Все команды ниже выполняются оператором по его решению. Приложение не устанавливает
PostgreSQL, не запускает системные службы и не меняет настройки хоста.

## Конфигурация

`.env` хранится вне Git; доступ к нему должен быть ограничен владельцем сервиса.
`POSTGRES_PASSWORD` задаёт пароль при первоначальном создании PostgreSQL-volume.
Изменение значения в `.env` не меняет пароль существующей роли: его нужно отдельно
сменить в PostgreSQL, затем обновить настройки и пересоздать API/worker.

`OPENAI_BASE_URL` включает путь API, например `https://api.openai.com/v1`.
`PUBLIC_ORIGIN` должен совпадать с адресом, который открывают пользователи,
включая схему и порт. `localhost` и `127.0.0.1` — разные origin.

В compose опубликован только HTTP-порт FastAPI на `127.0.0.1:8000`.
PostgreSQL наружу не опубликован. Worker и migrate работают отдельными сервисами.

## Обновление схемы

Миграции — отдельный шаг `migrate`; API проверяет ожидаемую версию при запуске.
`create_all` при старте не вызывается. Для следующей версии добавляется новая
миграция Alembic, существующие применённые миграции не редактируются.

Перед обновлением сделайте резервную копию. Остановите приём запросов и worker,
примените миграции, затем запустите новую версию. Для rolling update нужны совместимые
изменения схемы в несколько этапов; текущий compose предполагает обновление с паузой.

## Пользователи

```bash
docker compose exec app python -m app.manage create-user alice --name "Алиса"
docker compose exec app python -m app.manage set-password alice
docker compose exec app python -m app.manage disable-user alice
```

Смена пароля отзывает все сессии. Отключение пользователя отзывает сессии и переводит
его ожидающие задачи в ошибку. Уже отправленный провайдеру запрос может завершиться;
повторно войти отключённый пользователь не сможет. Самостоятельного восстановления
пароля через email нет; оно выполняется администратором через CLI.

## Резервные копии и восстановление

```bash
sh scripts/backup.sh ./backups
```

Скрипт создаёт custom-format `pg_dump`, сначала пишет во временный файл и переименовывает
его после успеха. Расписание, шифрование, внешнее хранение и срок хранения задаёт оператор.
Копии содержат переписки и хеши учётных данных; их доступ нужно ограничивать так же, как БД.
Named volume защищает от удаления контейнера, но не заменяет внешние резервные копии.

Восстановление сначала проверяется на **отдельной** БД. Для восстановления рабочей БД
API и worker должны быть остановлены; `--clean` удаляет существующие объекты:

```bash
docker compose stop app worker
docker compose exec -T db pg_restore -U vector -d vector --clean --if-exists < backups/selected.dump
docker compose run --rm migrate
docker compose up -d app worker
```

После восстановления из копии активные сессии можно отозвать удалением `login_sessions`
администратором БД. Перед открытием трафика проверить `/api/ready`, вход и чтение истории.

## Диагностика

- `/api/health` подтверждает работу HTTP-процесса.
- `/api/ready` возвращает 503 при недоступной БД или отсутствии heartbeat worker за 30 секунд.
- Ошибки API содержат `request_id`; HTTP-логи выводят его со статусом и временем ответа.
- Worker пишет ID генерации и итоговый статус, не содержимое переписки.
- `pending` означает, что задача сохранена и ждёт worker; `running` — запрос выполняется.
- `failed/interrupted` означает неопределённый результат после прерывания процесса.
  Автоматически повторять такой платный запрос нельзя.

Compose ограничивает размер логов и память процессов. Наблюдение за метриками, заполнением
диска, очередью, ошибками провайдера и расходами подключается к системе мониторинга окружения.
Данные переписок не удаляются автоматически по сроку; политику retention нужно определить
для конкретной команды. Пользователь может удалить собственные диалоги через интерфейс.

## Границы проверки

Изменения этой итерации не запускались по требованию пользователя. Проверка реального
LLM, применения/отката миграций, Docker-сборки и восстановления из backup должна
быть выполнена в выбранном окружении перед выдачей доступа пользователям.
